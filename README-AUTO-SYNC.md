# 🔄 Git自動同期スクリプト

Git連携からローカル同期までを自動実行するスクリプト群です。

## 📁 提供ファイル

### 🐧 Linux/Mac用
- **`auto-sync.sh`** - Bashスクリプト

### 🪟 Windows用
- **`auto-sync.bat`** - バッチファイル（コマンドプロンプト）
- **`auto-sync.ps1`** - PowerShellスクリプト（推奨）

## 🚀 実行方法

### Linux/Mac (Bash)
```bash
# 実行権限を付与（初回のみ）
chmod +x auto-sync.sh

# 実行
./auto-sync.sh
```

### Windows (コマンドプロンプト)
```cmd
# プロジェクトディレクトリで実行
auto-sync.bat
```

### Windows (PowerShell) - 推奨
```powershell
# 実行ポリシーの確認（初回のみ）
Get-ExecutionPolicy

# 必要に応じてポリシーを変更（初回のみ）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 実行
.\auto-sync.ps1

# オプション付き実行
.\auto-sync.ps1 -CommitMessage "カスタムコミットメッセージ" -Verbose
```

## 🔧 実行内容

このスクリプトは以下の処理を自動実行します：

### 1. 🔍 現在状態の確認
- 現在のブランチ確認
- 作業ディレクトリの確認

### 2. 📝 変更の検出とコミット
- 未ステージングの変更を検出
- 自動的に `git add .` を実行
- タイムスタンプ付きコミットメッセージで自動コミット

### 3. 🌐 リモート同期
- `git fetch origin` でリモート情報を取得
- `git push origin [現在のブランチ]` でローカル変更をプッシュ
- `git pull origin [現在のブランチ]` でリモート変更を取得

### 4. ✅ 同期状態の確認
- 最新コミット情報の表示
- リモート同期状態の確認
- 作業ツリーの状態確認

## ⚙️ PowerShellオプション

### 基本オプション
```powershell
# カスタムコミットメッセージ
.\auto-sync.ps1 -CommitMessage "新機能: 顧客管理画面の改善"

# 詳細出力モード
.\auto-sync.ps1 -Verbose

# 確認なしで実行（自動化用）
.\auto-sync.ps1 -Force

# 組み合わせ
.\auto-sync.ps1 -CommitMessage "更新" -Verbose -Force
```

## 🛡️ 安全機能

- **エラー時停止**: エラー発生時は処理を中断
- **状態確認**: 各ステップで状態を確認・表示
- **変更検出**: 変更がない場合は不要な処理をスキップ
- **カラー出力**: 重要な情報を色分けして表示

## 🔧 カスタマイズ

### コミットメッセージのカスタマイズ
スクリプト内の以下の部分を編集してください：

```bash
# auto-sync.sh の場合
COMMIT_MESSAGE="auto-sync: 自動同期 - $TIMESTAMP

🤖 Generated with [Claude Code](https://claude.ai/code)

Co-Authored-By: Claude <noreply@anthropic.com>"
```

### 追加処理の挿入
必要に応じて以下の処理を追加できます：
- データベースマイグレーション
- ビルドプロセス
- テストの実行
- 依存関係の更新

## 🚨 注意事項

1. **実行前の確認**: 重要な変更がある場合は事前にバックアップを取ってください
2. **ブランチの確認**: 正しいブランチで作業していることを確認してください
3. **権限の確認**: Gitリポジトリへのpush権限があることを確認してください
4. **ネットワーク**: インターネット接続が必要です

## 🔗 使用場面

- **開発セッション終了時**: 作業内容を確実にリモートに保存
- **ブランチ切り替え前**: 現在の作業を保存してからブランチ変更
- **定期バックアップ**: 定期的な作業内容の同期
- **チーム開発**: 最新の変更を取得してから作業開始

これらのスクリプトにより、Git操作を手動で行う必要がなくなり、開発効率が大幅に向上します。
