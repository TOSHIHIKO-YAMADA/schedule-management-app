# スケジュール管理アプリ

## 概要
組織向けスケジュール管理システム。アクティブユーザー500人対応。

## 技術スタック
- **フレームワーク**: Next.js 15.3.5 (App Router + Turbopack)
- **言語**: TypeScript (strict mode)
- **認証**: Clerk v6.12.9
- **データベース**: Prisma ORM + SQLite (開発) / Supabase (本番)
- **UI**: Shadcn/ui + Tailwind CSS v4
- **状態管理**: Zustand
- **フォーム**: React Hook Form + Zod
- **データフェッチング**: TanStack Query + Axios
- **日付処理**: date-fns

## 主要機能

### コア機能
- 個人スケジュール管理
- 車両使用予定の組み込み
- 繰り返し予定（曜日選択、終了日設定）
- 権限管理（スーパーアカウント、管理者、制限付き管理者、一般ユーザー）

### 車両管理
- 普通乗用車 10台未満の管理
- ナンバー・車両名での識別
- 車両空き状況一覧表示
- 重複予約時のアラート表示

### マスタデータ
- **従業員マスタ**: 社員番号、氏名（ふりがな）、TEL、LINE ID、通知方法、最寄り駅、移動手段
- **顧客マスタ**: 顧客名、住所、電話番号、担当者名
- **車両マスタ**: 車両名、ナンバープレート、車検満了日

### 通知システム
- メール通知
- LINE連携
- 車検満了日アラート

## 開発コマンド

```bash
# 開発サーバー起動（Turbopack）
npm run dev

# プロダクションビルド
npm run build

# プロダクションサーバー起動
npm start

# リント実行
npm run lint
```

## 開発環境要件
- Node.js 18.x 以上
- npm または yarn
